#  Speed Typing Test

A simple **Speed Typing Test** web app built using HTML, CSS, JavaScript, and Bootstrap.  
The app fetches a random quote and tracks how fast you can type it correctly.

##  Features
- Real-time timer starts when the quote loads
- Displays success message & stops timer when text matches
- Displays error message if text doesn’t match
- Reset button fetches a new quote and restarts timer
- Bootstrap spinner shown/hidden using `classList.add` and `classList.remove`
